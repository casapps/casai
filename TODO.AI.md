# TODO.AI.md — casai implementation backlog

Generated by `bootstrap` after PART 0–6 scaffolding. PART 0–6 (structure,
build system, Docker, metadata) is done — see the bootstrap completion
report. Everything below is PART 7 onward (feature implementation),
which bootstrap intentionally does not build.

No `auth`/`billing`/`notifications`/`support` builder agent applies —
this is a from-scratch single-user local CLI/TUI/GUI tool with no
multi-tenant server component (IDEA.md → "Roles / user types").

PART 14 (RFC protocol daemon) is explicitly out of scope for v1
(IDEA.md → "App surfaces in scope": "No RFC protocol daemon (PART 14) and
no local client/server (IPC) split in v1") — no backlog items for it.

→ cross-cutting (security, quality, docs, CI/CD, packaging). Each numbered
group below already reflects this order; PART number is the tiebreaker
within a group.
